# multi-crafter-lib

## 概述
Ls的自制mindustry模组拓展库，包含多配方工厂以及其它多种拓展类建筑基类，支持Java与Json模组调用，致力于给各位热爱mindustry的模组制作者提供便利
目前仍在优化与开发

## 内容
- 多配方工厂
- - （注：配置了为每个配方生成对应虚拟建筑的功能（用于与配方禁用与科技树解锁互动），副作用包括但不限于在地图编辑器中多出一些看上去重复的建筑）

- 可以选择当前单位生产配方的类Erekir组装厂
- - （注：允许选择不高于当前组装厂模块等级的所有配方，并允许同一模块等级有多个配方）
- 可进行全方向连接的物品与液体桥

- 除分类器之外的全套的物品液体混合运输元件（也包括上面的全方向桥类）
- 
- **（说明：以上均为可被用于制作建筑的基类，本模组除了数个示例建筑之外本身并没有具体内容，另外，所有建筑支持json进行完整配置）**
## 兼容性
- Mindustry 游戏版本 >= v159
